# Linux legacy open and creat

The Linux personality admits open and creat on i386, x86_64, ARM32, MIPS O32, MIPS N64 and PPC32 using syscall numbers independently crosschecked against Linux6.13.4 and musl1.2.5. AArch64, RV32/RV64 and LoongArch64 have no such legacy entries; their public musl open/creat functions use openat. No legacy number is synthesized for those profiles.

The adapter copies a bounded pathname and normalizes target int/umode_t scalars into the existing OpenCodec/openat_limited operation. Legacy calls start from the retained current-directory object through AT_FDCWD. creat constructs target O_CREAT|O_WRONLY|O_TRUNC; it preserves an existing inode's mode and truncates only after existing admission succeeds. The common descriptor service keeps pre-mutation resource checks, permissions, symlink policy, CLOEXEC/status flags and node references. 64-bit native calls admit large regular files; 32-bit raw open requires O_LARGEFILE, while raw creat has no flags parameter and retains its 32-bit size admission. Pinned musl supplies its own large-file policy.

This adds two generated Operation entries and changes the exported ProfileData array. The provisional SDK13 union requires complete producer/consumer rebuilding; separately produced earlier provisional13 artifacts are not interchangeable. Native UAPI0.4.0 is unchanged.

The qualified flag subset remains the same as openat. O_PATH, O_TMPFILE, full synchronous/direct-I/O behavior, controlling-terminal acquisition and libc cancellation are not implemented. These entries do not add full stat metadata, dynamic linking, signals, threads, native SMP or physical-device support.

The retained all-ten openat/sync hosted suite gains real legacy-adapter calls on the six applicable profiles, explicit absent-number checks on four generic profiles, cwd rename identity, permission/mode and scalar narrowing, EFAULT, full-fd admission without create/truncate and large-file preflight. Hosted mappings are not guest execution. The cumulative musl probe adds public open/creat on all ten, raw legacy calls where present, CLOEXEC and shared flags, pointer errors and descriptor pressure, with exact persisted file bytes verified offline. Two complete markers plus all earlier probe suites are required by --require-open; the workstation qualifier exposes --musl-open. Source/evidence receipts separately record compilation, hosted checks, native runs and old-kernel negative controls.
